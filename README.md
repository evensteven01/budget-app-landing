# Working Budget — Beta Landing Page

**Project docs:** [project-docs/budget-app](https://github.com/evensteven01/project-docs/tree/main/budget-app) · **Board:** [Fordsoft Development → budget-app](https://github.com/users/evensteven01/projects/5/views/6)

Issues for this repo are filed on [`budget-app-mobile`](https://github.com/evensteven01/budget-app-mobile/issues); PRs here close them with `Fixes evensteven01/budget-app-mobile#<n>`.

Static one-page site recruiting beta testers for `budget-app-mobile` (the pay-period
budgeting app, working name "Working Budget") from outside the personal
friends/coworkers network — see
[budget-app-mobile#67](https://github.com/evensteven01/budget-app-mobile/issues/67) for the
full context and decisions behind this page.

- Hosted via GitHub Pages at `budget.swcraftsman.com` (see `CNAME`).
- No backend: the "Apply" button links out to a Google Form. No build step, no dependencies
  — just `index.html`.
- Not the product's marketing/SEO site — see
  [budget-app-mobile#57](https://github.com/evensteven01/budget-app-mobile/issues/57) for
  that separate, later effort.

## Editing

Edit `index.html` directly, commit, push to `main` — GitHub Pages redeploys automatically.
